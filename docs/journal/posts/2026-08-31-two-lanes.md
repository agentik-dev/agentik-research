# Two lanes

Agents that write to each other pay for every word, so they compress. A person who reads their notes later can be left outside. agentik-respeak keeps two lanes: governed shorthand between agents, and plain, gated prose for people. One editorial pass on one document is the whole of its evidence, and the drift it answers is not recorded anywhere in its repository's history.

<!-- more -->

## The problem

An unattended run is a chain of sessions handing work to each other through notes, packets and charters. Each token in those notes costs context, so the pressure to compress is built in. respeak's README states the risk in one sentence: "They drift into shorthand, and the person supervising the run becomes the outsider."[^readme]

A note the person cannot read is a run the person cannot audit.[^readme]

## A human example: abbreviations that kill

Clinicians write orders in shorthand. The harm comes when a reader takes one short form for another. The Joint Commission's "Do Not Use" list names the short forms that readers misread. "U" for unit is misread as zero, as four or as "cc". "IU" is misread as IV or as 10.[^jc] "QD", daily, is the most common problem, because it can be mistaken for "q.i.d.", four times a day.[^drugtopics] The list applies to every handwritten order and medication record, free-text computer entry and pre-printed forms included.[^jc]

The ban did not start that narrow. The accreditor's first goal called for eliminating many common abbreviations at once, with pharmacists told to reject such orders. It then narrowed where the ban applies: to handwritten, pre-printed and free-text entries in patient care and medication records.[^drugtopics]

## What the research teaches

The [telling-people chapter](../../field/telling-people.md) finds the premise rests on human pairs, not on agents. Herbert Clark and Deanna Wilkes-Gibbs had pairs describe the same abstract figures over six rounds; the words per figure fell from 41 to 8.[^clark] People who overheard the whole conversation matched the figures 88 percent of the time, against 99 for the partner. Overhearers who joined late averaged 68 percent.[^schober] A private shorthand works inside the pair and costs everyone else.

No source records an agent dialect locking a person out, and a search of respeak's own history found no such incident.[^chapter] What the field has measured is the human lane's other failure: machine prose has tells. In 2024 biomedical abstracts, "delves" appeared 28.0 times as often as expected, and at least 13.5 percent of the abstracts were processed with a language model.[^kobak]

## What we built

respeak keeps the two lanes apart.[^readme]

- **The machine lane.** Agents may use only shorthand that a person has ratified in a lexicon, and write everything else in full. Entries are proposed, ratified or retired, never silently edited. Error messages, security findings, a user's quotes and numbers with units are never compressed.
- **The human lane.** A translator renders the work for a person in one of three modes: eli5 for a newcomer, bluf for a manager, technical for a peer engineer. Every mode passes the same gate: 234 banned phrases in 22 categories, 96 of them errors, and 60 replacement rules.[^corpus]

The README names the two alternatives it rejects. Forcing prose on agents pays the attention cost on every message. Letting the dialect drift gives up auditing your own automation.[^readme]

This site runs the same gate: its `make check` runs `make style`, which calls respeak's check on every page.[^makefile]

## Does it work?

<div class="ak-verdict" markdown>

<span class="ev ev-our-use">our use</span> One field test, n=1: one editorial pass over one 4,000-word internal design document. The README calls the numbers "sizing evidence, not a benchmark".

</div>

The README's own table:[^readme]

| Measure | Before | After |
|---|---|---|
| Banned phrases, error severity | 3 | 0 |
| Banned phrases, warn severity | 9 | 1 |
| Em-dashes per 1,000 words | 19.9 | 3.1 |
| Average sentence length | 32.1 words | 24.5 words |

The pass changed no heading, link, code or number, and the verifier proves that.[^readme] Three limits weaken the rest. The source documents were removed as unpublishable, so the test cannot be re-run.[^changelog] A later sentence splitter made every earlier sentence-length figure stale.[^changelog] And nobody measured whether a reader understood the after-text better than the before.

## What has not worked, and what is open

The machine lane is barely used. The lexicon holds two ratified terms and one proposed term. Each carries a use count of 0, and no script writes that count.[^corpus] We cannot say whether agents use the shorthand, because nothing counts it.

The drift itself is still a premise. respeak guards against a failure its repository asserts and has not recorded.[^chapter]

The gate checks phrases and lengths, not understanding. A page can pass it and still mislead. The README ranks translator error high: "a confident wrong BLUF is worse than shorthand".[^readme]
