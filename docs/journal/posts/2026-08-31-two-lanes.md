# Two lanes

agentik-respeak starts from a premise: agents that write to each other drift into shorthand, and the person who reads the run is left outside. It keeps two lanes: governed shorthand between agents, and plain, gated prose for people. Its evidence is our use: one field test on one document, then later editorial passes over the owner's sites and over its own README. The README reports no reader study, and a search of the repository's charters found no recorded case of the drift.

<!-- more -->

## The problem

In an unattended relay run, one session hands its work to the next. Agents that write to each other spend context on every token, so respeak's README calls the pressure to compress structural. It states the risk in one sentence: "They drift into shorthand, and the person supervising the run becomes the outsider."[^readme]

A note the person cannot read is a run the person cannot audit.[^readme]

## A human example: abbreviations that kill

Clinicians write orders in shorthand. The harm comes when a reader takes one short form for another. The Joint Commission's "Do Not Use" list names the short forms that readers misread. "U" for unit is misread as zero, as four or as "cc". "IU" is misread as IV or as 10.[^jc] "QD", daily, is the most common problem, because it can be mistaken for "q.i.d.", four times a day.[^drugtopics] The list applies to every handwritten order and medication record, free-text computer entry and pre-printed forms included.[^jc]

The ban did not start that narrow. The accreditor's first goal called for eliminating many common abbreviations at once, with pharmacists told to reject such orders. It then narrowed where the ban applies: to handwritten, pre-printed and free-text entries in patient care and medication records.[^drugtopics]

## What the research teaches

The [telling-people chapter](../../field/telling-people.md) finds the premise rests on human pairs, not on agents. Herbert Clark and Deanna Wilkes-Gibbs had pairs describe the same abstract figures over six rounds; the words per figure fell from 41 to 8.[^clark] People who overheard the whole conversation matched the figures 88 percent of the time, against 99 for the partner. Overhearers who joined late averaged 68 percent.[^schober] A private shorthand works inside the pair and costs everyone else.

No source records an agent dialect locking a person out. A search of respeak's 41 working-session charters found no such case either; that is a negative result, not proof.[^chapter] What the field has measured is the human lane's other failure: machine prose has tells. In 2024 biomedical abstracts, "delves" appeared 28.0 times as often as expected, and at least 13.5 percent of the abstracts were processed with a language model.[^kobak]

## What we built

respeak keeps the two lanes apart.[^readme]

- **The machine lane.** Agents may use only shorthand that a person has ratified in a lexicon, and write everything else in full. Nothing intercepts their traffic: each session loads a digest of the lexicon through a CLAUDE.md import. Entries are proposed, ratified or retired, never silently edited.[^readme] A `never_compress` list names the classes to keep verbatim, among them error messages, security findings, a user's quotes and numbers with units. The list is instruction-only: the translator's prompt names it and no script checks it, though the verifier holds numbers across an editorial pass.[^config]
- **The human lane.** A translator renders the work for a person in one of three modes: eli5 for a newcomer, bluf for a manager, technical for a peer engineer.[^readme][^config] Every mode passes the same style gate: 234 banned phrases in 22 categories, 96 of them errors, and 60 replacement rules.[^corpus]

The README names the two alternatives it rejects. Forcing prose on agents pays the attention cost on every message. Letting the dialect drift gives up auditing your own automation.[^readme]

This site runs respeak's gate on its own pages: `make check` runs `make style`, which calls respeak's `respeak-check.sh` on `docs/**/*.md` and `README.md`.[^makefile][^siteconfig] It is not quite the same gate. respeak ships an empty `gate.allow` list.[^config] This site's list skips two corpus rules of error severity, `delve` and `synerg(y|ies|istic)`, because cited paper titles carry those words.[^siteconfig][^corpus]

## Does it work?

<div class="ak-verdict" markdown>

<span class="ev ev-our-use">our use</span> One field test, n=1: one editorial pass over one 4,000-word internal design document, which the README calls "sizing evidence, not a benchmark". The CHANGELOG adds a pass over the README and a ten-agent pass over about 2,000 files of the owner's sites, which found faults in the tooling. The README reports no reader study.

</div>

The README's own table:[^readme]

| Measure | Before | After |
|---|---|---|
| Banned phrases, error severity | 3 | 0 |
| Banned phrases, warn severity | 9 | 1 |
| Em-dashes per 1,000 words | 19.9 | 3.1 |
| Average sentence length, before the 2026-09-21 splitter | 32.1 words | 24.5 words |

The README reports that the pass changed no heading, link, code or number, with `respeak-verify-edit.py` passing.[^readme] That check is structural. The script holds inline code spans and numbers only as multisets, and the README says it does not check facts.[^verify][^readme] Before version 0.6.0, its heading rule needed a space after the hashes, so a hard-wrapped line beginning `#33256` published as an H1 while the verifier passed the edit. The 2026-08-31 test predates that fix.[^changelog]

Three more limits. Version 0.5.0 removed the field-test source documents as unpublishable, so the README keeps the numbers as measured and the test cannot be re-run from the repository.[^changelog][^readme] Version 0.6.0's sentence splitter made every earlier sentence-length figure stale; under it, the README's own average fell from 15.1 to 13.0 words with no prose changed.[^changelog] And no row of the table measures a reader.[^readme]

The CHANGELOG records two later passes.[^changelog] In version 0.5.2 the README itself went through the translator's editorial pass. Its average sentence fell from 23 to 15 words, a pre-0.6.0 figure, and every heading, link, code block, code span and number stayed byte-identical, as checked by the verifier. In version 0.6.0, a ten-agent editorial pass over nine of the owner's sites, about 2,000 edited files on 2026-09-21, found faults in the tooling, and the release changed the tool for each:

- A banned term inside a heading, which the verifier holds byte-identical, shut the file to every later edit.
- The splitter read a bullet list as one sentence, so one site measured an average sentence of 68.9 words.
- A hand audit run without the project's configuration reported 36 errors against 13 real ones on one site's baseline.
- The `#33256` line above published as a heading.[^changelog]

## What has not worked, and what is open

Use of the machine lane is not counted. The lexicon holds two ratified terms and one proposed term. Each reads `uses: 0`, and the lexicon's header says the counter is declared, not built: no script writes it yet.[^corpus]

The drift itself is still a premise. The README asserts it in one sentence, and the search of the charters found no recorded case.[^readme][^chapter]

The gate scans phrases and sentence lengths, and the verifier checks structure. The verifier does not check facts: the README says an appended false paragraph, or a "never" turned to "always", passes it. Until a deferred invariant lands, facts rest on the translator's rule to add no fact and drop none.[^readme] respeak's risk register, which the README cites, ranks translator error high: "a confident wrong BLUF is worse than shorthand".[^readme]
