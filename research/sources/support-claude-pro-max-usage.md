## What it says
- Pro and Max plans have a five-hour session limit and a weekly limit, as of October 2026. The page gives no prompt counts or hour allotments. Warnings appear as you near a limit.
- Max plans also have a separate weekly limit for Fable. The page does not mention separate Opus or Sonnet limits (the Claude Code error reference does, see code-docs-errors-usage-limits).
- Claude Code and Claude chat share the same limits: "all activity in both tools counts against the same limits"; usage in IDE extensions counts too. The page does not say whether subagents share limits with the main conversation (the Claude Code subagents page says they do).
- At a limit, Pro users can enable usage credits, upgrade to Max 5x, or switch to a Console account with API credits; Max users can enable usage credits after the five-hour, the general weekly or the Fable weekly limit, or upgrade to Max 20x. Credits bill at standard API rates. Monthly API credits included with Max cannot be used in Claude Code or the Claude apps, including for extra usage. `/status` shows the remaining allocation.
