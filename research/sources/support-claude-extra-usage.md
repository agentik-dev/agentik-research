## What it says
- As of October 2026, usage credits let Pro, Max 5x and Max 20x subscribers keep working after they hit included limits by moving to pay-as-you-go pricing instead of being blocked. They are separate from the monthly API credits included with Max and Team, which do not apply to usage credits.
- They start after the five-hour session limit, the weekly limit or, on Max plans, the separate weekly Fable limit is used up. Billing is at standard API rates (the page points to the pricing page); charges appear as additional charges on the bill.
- The subscriber sets a monthly spending cap or chooses unlimited, prepays with "Add funds", and can set auto-reload. Claude Code is covered: terminal usage and chat count toward the same limits. Usage credits do not change when regular limits reset; they can be turned off in Settings > Usage.
- The page does not mention fast mode, and does not mention organisation-, group- or member-level limits (the Claude Code costs page describes those for Teams and Enterprise).

## Limits
- I read an extract, not the page layout. The page does not state a unit for billing beyond "standard API rates" and no minimum purchase.
