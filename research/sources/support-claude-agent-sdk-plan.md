## What it says
- Update banner of 2026-06-15, as the fetch tool extracted it twice: the previously announced changes to Agent SDK usage were paused. For now, Agent SDK, `claude -p` and third-party app usage still count against the subscription's usage limits.
- Update banner of 2026-10-07: Claude Max and Team plans now include monthly API credits. The credits are described as covering the Claude Agent SDK, `claude -p`, the Claude API and Claude Managed Agents. The amounts and the exact coverage are on a linked article (support-claude-api-credits-max-team), which narrows `claude -p` to runs with an API key from the linked Console organization.
- Related-article list names plan-specific pages for Pro and Max, Team and Enterprise, login, Fable on plans, and the monthly API credits.

## Limits
- I read the page only through the fetch tool's extract, which would not reproduce the full text; the wording above is the extract's, not verbatim. The two banners and the linked article do not obviously agree on whether `claude -p` is covered by the credits; the linked article is more specific. As of October 2026.
- Third-party pages (not opened by me) describe a 2026-06-15 change as in force; this Anthropic page says it was paused. See the disputes in research/synthesis/field-10.md.
