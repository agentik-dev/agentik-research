## What it says
- Severity runs from blocker to trivial. The page defines only the two ends: blocker means the application is unusable, and trivial means a minor cosmetic issue. Critical, major, normal and minor are listed without definitions.
- The same field can mark a bug as an enhancement request.
- Priority takes the values P1 to P5 by default, ranks the work, and is meant to be set by the assignee or by someone with authority over that person's time. The page advises against changing priority on other people's bugs.

## Limits
- The shipped field values are defaults that an installation can change. The page gives no counts, rates or outcomes.
